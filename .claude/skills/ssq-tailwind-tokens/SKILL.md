# Tailwind v4 + токены «Ночной меди» — SSQ-site

Источники решений: `docs/design.md` (дизайн-система) и `docs/specs/ssq-site-stack-design.md`
(§5, значения токенов). Докс главнее скилла; при расхождении — править оба и
сказать владельцу. Направление «Ночная медь» + инженерные акценты.

## Токены — единственный источник design-значений

- Все цвета/шрифты/отступы/радиусы — только через CSS-переменные
  `site/src/styles/tokens.css`; в компонентах не хардкодить. Tailwind-утилити-классы
  допустимы, но design-значения текут через токены (Tailwind настраивается на
  переменные, не дублирует значения).
- Палитра (design.md):

| Токен | Значение | Роль |
|---|---|---|
| `--color-bg` | `#101014` | фон (чуть холоднее референса #101010) |
| `--color-surface` | `#17191d` | карточки |
| `--color-text` | `#eceae6` | основной текст |
| `--color-text-muted` | `#9a9a9a` | вторичный текст |
| `--color-accent` | `#c9a15a` | медь: кнопки, цифры, пунктирные подчёркивания |
| `--color-accent-contrast` | `#101014` | текст на медном |
| `--color-line` | `#2a2d33` | линии/бордеры |
| `--radius-s` | `2px` | карточки/кнопки — почти прямые |
| `--border-accent` | `3px solid accent` | левый бордер карточек |

- Шрифты: заголовки Lora (антиква), текст/UI Manrope, моно-акценты
  JetBrains Mono; все с полной кириллицей, Google Fonts, `font-display: swap`,
  локальный фоллбек-стек обязателен. Моно-детали: логотип-метка `SSQ //`,
  телефон, технические подписи, нумерованные блоки `01 / 02 / 03`.

## Когда хардкод всё-таки встречается

Значений нет в токенах — сначала добавить токен в `tokens.css`, потом
использовать. Исключение для одноразовой величины — только если и владелец
согласен, и повторения не видно (оценить: заголовок-кейс vs системная величина).

## Приёмы направления

- Карточки: поверхность + контрастный левый медный бордер 3px, радиус ~2px.
- Hero: full-bleed фото + градиент затемнения снизу; до съёмки (план, шаг 11)
  — тёмно-бронзовый градиент-фоллбек.
- BEM-нейминг из референса не переносится: классы даёт Tailwind, смысл —
  через токены и компоненты. FAQ — `<details>` без JS.

## Доступность и анимации

- `prefers-reduced-motion: reduce` отключает анимации.
- Контраст `--color-text-muted` на `--color-bg` — WCAG AA для мелкого текста;
  контраст медного акцента проверять при его использовании для текста.
- Dark-mode-переключателя нет: тема одна («Ночная медь»).

## Проверка стилизации перед завершением

1. В компоненте нет хардкода цветов/шрифтов/отступов — всё через токены
2. на ~400px нет горизонтального скролла (qa.md)
3. `prefers-reduced-motion` уважен
4. `astro build` проходит
