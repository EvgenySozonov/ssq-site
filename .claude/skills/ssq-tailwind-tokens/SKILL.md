## Токены — единственный источник design-значений

- Все цвета/шрифты/отступы/радиусы — только через CSS-переменные `tokens.css`;
  в компонентах не хардкодить. Tailwind-классы допустимы, design-значения текут через токены.

## Шрифты

- Текст/UI/display: **Manrope** (подстановка референса за отсутствующий Systemia;
  weights только 400/500 — display никогда не жирнее 500; полная кириллица, Google Fonts).
- Крупные числовые выноски: **Azeret Mono 500** (только цифры — кириллицы в фонте нет).

## Приёмы направления

- Канва крем; тёмные секционные банды — Espresso `#2c2722` с Porcelain-текстом.
- Карточки: фон (bg на цветной банде / surface), hairline-бордер `--color-line`, радиус 10px,
  **без теней** — глубина создаётся полями цвета, не elevation.
- Конверсионная кнопка: Espresso-пилл 20px, cream-текст, паддинг `pl-6 pr-5`, стрелка `→`
  в правом кармане (`justify-between gap-6`).
- Поля формы: **Espresso Underline Input** — прозрачные, подчёркнутые 1px `--color-line`,
  радиус 0, фокус — `border-text`.
- Типографика: UI/навигация 14px/500 caps; заголовки секций 3xl–4xl/500;display-заголовки
  hero `text-5xl sm:text-7xl`/500; «01 //»-подписи — caps 12px muted (наследие SSQ).
- Ссылки-«капсы»: не оставлять без явного цвета (`text-text`) — иначе браузерный синий дефолт
  у якорей без классов цвета (ловлено на приёмке 2026-11-17).

## Запреты (Do/Don't референса)

- Не чёрный #000, не синие/зелёные/красные «статусные» акценты; палитра — крем/espresso/stone/yellow/peach.
- Не добавлять drop-shadow; не скруглять inputs/табы (0px); не 9999px для карточек и конверсионных кнопок.
- Wash-цвета (#fdf0c7, #fdc6b3) — только широкими секционными бандами.

## Проверка стилизации перед завершением

1. В компоненте нет хардкода цветов/шрифтов/отступов — всё через токены
2. на ~400px нет горизонтального скролла (qa.md)
3. `prefers-reduced-motion` уважен
4. `astro build` проходит
