# Деплой и секреты

- Следуй скиллу `ssq-deploy-beget` (выкат, откат, гейты, smoke-тест).
- Жёсткий гейт: `.env` в git не попадает никогда — только `.env.example`.
- Прод-секреты: `/home/<user>/.env-ssq` вне docroot; новые токены — не
  печатать и не коммитить, дать владельцу команду ручной установки.
- Перед выкатом: гейты 1–8 скилла деплоя по порядку.
