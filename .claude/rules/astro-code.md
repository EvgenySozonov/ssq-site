# Правки кода Astro-каркаса (site/src)

- Следуй скиллу `ssq-astro-conventions` (каркас, данные, острова, SEO).
- Гейты перед завершением любой правки: `npm run lint && npm run check &&
  astro build` (в `site/`) — зелёные, иначе работа не завершена.
- React-остров только с названной причиной (интерактивность); всё остальное
  — ноль JS.
- Активные данные — в `site/src/data/`, контакты — только из `site.json`.
