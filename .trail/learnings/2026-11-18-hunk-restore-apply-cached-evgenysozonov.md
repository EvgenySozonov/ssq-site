Расщепление правок одного файла (SSQ README) между двумя атомарными коммитами: hunk-фильтр по diff-патчу

## Decided
Правка одного файла распадается на два логических изменения — коммитить не целиком: git diff > патч → python-фильтр хунков по содержимому добавленных строк → git restore файла → git apply --cached отфильтрованного патча → коммит с этим файлом; оставшиеся хунки идут вторым коммитом обычным git add. После обоих коммитов дерево чистое и рабочее дерево консистентно.

## Tried and ruled out
git add -p — непригодно в среде агента: интерактивные флаги не поддержаны. Класть оба изменения в один коммит — отклонено: владелец просил три атомарных коммита, смешение ломает ревью.

## Watch out
git restore рабочего файла ДО apply --cached обязателен: патч правит индекс, рабочее дерево должно остаться со вторым изменением. Патч-фильтр собирать по содержимому добавленных строк (маркер «Прослеживаемость»), не по строковым позициям hunk-хедера — они смещаются.

## In the code
