## 2026-10-18. Инструментарий качества
- vitest — тесты lib-слоя (`data.ts`, `format.ts`, zod-схемы); TDD-порядок для lib. Установка — devDependency в `site/`.
- Playwright MCP — UI-приёмка (h-скролл, навигация, error-ветка формы, FAQ); рукам остаётся финальный скриншот-просмотр.
- claude-security:scan — перед каждым релизом; CONFIRMED-находки блокируют выкат.
- fewer-permission-prompts — allowlist операций сессии, чтобы Native-исполнение не тонуло в однотипных подтверждениях.

## 2026-10-17. Форма — Python CGI вместо PHP
- Выбор владельца (вариант 2 из трёх): языковой комфорт обслуживающего + готовое плечо для будущих адаптеров на Python.
- Beget Shared поддерживает Python (CGI/FastCGI и WSGI/Passenger); выбран **CGI на голом stdlib** — из двух путей самый простой: без venv, ACL и restart.txt, которые требует Passenger.
- Секреты: `/home/<user>/.env-ssq` вне docroot, читается скриптом.
- Источник: beget.com/ru/kb/how-to/web-apps. Дополнительно 2026-10-17: Docker для проекта отложен (YAGNI) — `.nvmrc` на старте, compose-файл отдельно, когда появится второй процесс (CRM-адаптер).

## 2026-10-17. C4-модель в Structurizr DSL; Docker принят для тулинга
