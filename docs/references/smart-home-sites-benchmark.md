# 5. Выводы для SSQ-site

1. **Открытые цены — дифференциатор.** Подавляющая часть RU-рынка прячет суммы. Паттерн comf.life/butlerdc/i-ntelligent (цены в кейсах + тарифы проектирования открыто) поддерживает премиум-позиционирование SSQ (аудитория «сначала смотрят работы и цены» — docs/product.md).
2. **Полный цикл — прописать явно.** Формулировка smartknx.ru «один интегратор ведёт всё» — готовый каркас для секции процесса на `/services/elektromontazh/` и `/services/umniy-dom/`.
3. **Портфолио с результатами и ценами** — эталон из butlerdc/4фазы/i-ntelligent: каждый кейс = объект + бюджет + статус «объект сдан».
4. **Первый экран: цифры доверия** (liis.su: годы, объектов, специализаций) + CTA «Бесплатный выезд для замера».
5. **Сценарная подача** «A Day In The Life» (Bethesda Systems) — секция сценариев на `/services/umniy-dom/` без глубокого погружения в протоколы. Развёрнутый образец полным текстом (утро/день/вечер/«Goodnight») — на [lifetronic.net/smart-home/](https://lifetronic.net/smart-home/).
   - Там же два приёма для `/services/`: интерактивный селектор «What's most important to you?» (9 тем интереса вместо плоского списка) и лид-магнит PDF «Smart Home Solutions Guide» (имя+email → гайд) как мягкая альтернатива заявке.
   - Форма с квалификатором (dropdown «I am interested in»), honeypot-поле и блок именных отзывов клиентов.
   - Geo-шаблон посадочных по городам (Greenwich, New Canaan, Scarsdale…) — потенциально для SSQ при выходе за Москву и область (позже).
6. **Калькулятор** — отложить до этапа «калькулятор (позже)» по product.md; референсы реализации: konstartstudio.ru (продуктовый), xiot.ru, Bethesda Systems («Calculate your Budget»).
7. **Структура услуг по 2 осям** (Elevated Integration: по сервису / по сектору) — совместима с каркасом направлений SSQ (lines.json) на этапе «услуги расширятся».

Сильные прямые аналоги SSQ (электромонтаж + умный дом в одной компании): **regent5.com, bocatech.com** (мир), **4фазы.рф, comf.life** (RU).

# 6. Методология и уровень достоверности

- Сбор: поиск по RU/EN (4 запроса), затем независимая перепроверка двумя агентами.
- Раздел 1: проверено прямой загрузкой сайтов (curl, HTTP 200) 2026-11-15 — высокая достоверность.
- Раздел 3: по поисковой выдаче, загрузкой не проверено — средняя достоверность.
