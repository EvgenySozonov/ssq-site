# Global Wave Integration — брендинг в токенах design.md

# Назначение

- Токенизация брендинга GWI (`globalwaveintegration.com`) в формате токенов SSQ
  ([design.md](../design.md)) — как референс-словарь приёмов, не как замена «Ночной меди».
- Источник: Firecrawl `scrape --format branding`, главная, 2026-11-17; confidence 0.925
  (colors 0.86, buttons 0.99). 1 кредит. Скриншот главной — [globalwaveintegration-home.png](globalwaveintegration-home.png).

# 1. Токен-таблица GWI

Роли токенов — по словарю SSQ ([design.md](../design.md), ssq-tailwind-tokens).

| Токен SSQ | Значение GWI | Роль / наблюдение |
|---|---|---|
| `--color-bg` | `#FFFFFF` | светлый фон (GWI colorScheme: light) |
| `--color-surface` | — (не обнаружен) | у GWI отсутствует: карточки = белый на белом с границами 0–1px |
| `--color-text` | `#1F2124` | основной текст (из компонентов input; branding даёт `textPrimary #007562` — бирюзовый текст, в компонентах не подтверждён) |
| `--color-text-muted` | `#69727D` | вторичный текст / подписи |
| `--color-accent` | `#007562` | глубокий тёмно-бирюзовый (teal), кнопки/ссылки |
| `--color-accent-contrast` | `#FFFFFF` | текст на бирюзовом |
| `--color-line` | — (null) | границы у input отсутствуют, вид зависит от placeholder/фона |
| `--radius-s` | `3px` | контейнеры/input — почти прямые |
| радиус кнопок | `50px` | **пилл**: primary и secondary — полные таблетки (контраст к почти прямым контейнерам) |
| сетка | baseUnit `4px` | 4-пиксельный базовый шаг отступов |
| `font-sans` (text/UI) | **Inter** | body/paragraph; Google Fonts, полная кириллица есть |
| `font-display` (заголовки) | **Maharlika** | кастомный дисплейный (не Google Fonts); в hero гигантские serif-строки капсом |
| размер h1 | `125px` (desktop) | один из самых крупных h1 у интеграторов; на mobile кластер — проверить нечем |
| размер h2 | `50px` | |
| размер body | `18px` | |
| кнопка primary | bg `#007562`, text `#FFFFFF` | pill |
| кнопка secondary | bg `#FFFFFF`, text `#007562` | pill, без тени |
| input | transparent, радиус 0 | минимализм форм |

Тень: `none` у всех компонентов — глубина достигается фото и размером шрифта, не тенями.

# 2. Дыры и недостающие токены (scrape не покрыл)

- **Тёмный слой hero**: branding отдал `colorScheme: light`, но на скриншоте первого экрана —
  тёмный слайд-фон и тёмная «таблетка»-навигация (визуально тёмный teal ≈ `#0d2f28`, не подтверждён hex'ом).
  Значение из CSS-переменных сайта GWI требует ручного разбора CSS — не сделано в этом проходе.
- **Акцент `#D9534F`** (красный, из палитры scrape): на скриншоте и в извлечённых компонентах
  не виден. Похоже на артефакт сжатия (bootstrap-красный) — **не переносить** без ручной проверки.
- Тёмные варианты текста/фона, hover-состояния, focus-кольца, mobile-типографика — scrape
  брендинга один страницы всё это не покрывает.

# 3. Контраст с «Ночной медью» (что осмысленно сравнивать)

| Ось | «Ночная медь» (SSQ) | GWI | Вывод |
|---|---|---|---|
| База | тёмная `#101014` | светлая `#FFFFFF` | непрямо копируемая база — противоположная тема |
| Акцент | медь `#c9a15a` | teal `#007562` | другой полюс; teal — не кириллический тренд-цвет, а люкс-код США |
| Заголовки | Lora 3xl/4xl | Maharlika 125px | масштаб: GWI играет гигантским serif; SSQ — композиции |
| Кнопки | радиус 2px | pill 50px | у GWI пилл-кнопки — фирменный приём |
| Тень/свет | без теней | без теней | совпадает |
| Моно-детали | JetBrains Mono (SSQ //) | нет моно-слоя | «Ночная медь» несёт инженерный код, GWI — нет |

**Переносимое в SSQ без смены темы**: пилл-кнопки (по решению владельца), масштаб display-типографики
на hero, светлые секции-противопоставления внутри тёмной базы. **Не переносимо**: сам teal/светлая база —
это другой люкс-код.

# 4. Методология и достоверность

- Scrape `--format branding` одной страницы (главной): machine-extracted, галлюцинации исключены,
  но coverage ограничен: цвета/шрифты/типографика/кнопки/inputs — надёжно (0.86–0.99),
  тёмный слой hero и hovers — не покрыты (раздел 2).
- Скриншот главной 1920px (тот же день) — сверка на противоречия; противоречие «light vs тёмный hero»
  описано выше, не отфильтровано, а помечено.
- Перепроверка независимым агентом не запускалась: извлечение машинное, источники приложены.
