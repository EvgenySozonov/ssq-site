# Назначение файла

- Индекс порядка реализации: шаг → задачи детального плана → статус.
- Живой документ с шагами и кодом — **[plans/ssq-site-implementation-plan.md](plans/ssq-site-implementation-plan.md)**: детальные статусы ведутся чекбоксами задач там. Здесь — только общее состояние шага.
- См. также: [architecture.md](architecture.md), [product.md](product.md), спека — [specs/ssq-site-stack-design.md](specs/ssq-site-stack-design.md).

# Границы

- Старая визитка `src/index.html` остаётся как референс, не переносится.
- Блог и калькулятор — после первого релиза (отдельные планы).
- Политика ПДн входит в шаг 3 (форма без неё не выкатывается) — правило из спеки §6.3.
