# Usability-review example/index.html — отчёт
Дата: 2026-11-02 · Метод: эвристики Нильсена, ssq-usability-heuristics · Ширины: desktop (код/DOM), ~400px (Playwright)

## Итог
Пробное ревью по скиллу ssq-usability-heuristics референс-визитки (макет без прод-формы). Находок: 8 —
0×4, **2×3 (одна — blocks conversion: нет `tel:` в шапке)**, 4×2, 2×1. Обе находки №3 —
обязательны к переносу в прод-каркас `site/`. Для референса-макета страница работоспособна.

Не проблемы / принятые решения
- Меню: Escape, клик по пункту, фокус-возврат на кнопку открытия (main.js:12–33) — эвристика 3 ок.
- FAQ `<details>` скрывается, вопросы контекстны решению — эвристика 10 ок; шаги процесса 01–04 конкретны.
- Язык текстов — язык заказчика, без разработческого жаргона — эвристика 2 ок.
- `input type="tel"` (index.html:283), labels-обёртки, 17px у input (style.css:507–509, анти-зум iOS).
- `prefers-reduced-motion` учтён (style.css:220, 548) — вне профиля скилла, но подтверждено.
- Телефон достижим из оверлей-меню и секции контактов (эвристика 6 частично закрыта); находка 1 — именно про шапку/футер.
- Текст success-состояния макета «Заявка зафиксирована локально (макет кнопки)» (main.js:57) — честная пометка макета, оставить только здесь; в проде — заменить на понятный текст + следующий шаг.
