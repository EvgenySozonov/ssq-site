# Умный квадрат — Solstice (Style Reference)

> Редизайн 2026-11-18: тема Solstice (Hallmark, draw 0f0a46), по выбору владельца.
> Лок система. Источник правды при расходах: этот файл + `site/src/styles/tokens.css`.
> Замена прежнего референса AYOCIN (история в git).

## Материал

Крем-бумага, тёплый коричневый чернильный текст, один вермильон-сигнал, золотые
волосяные линейки, квадратные поверхности на жёсткой «бумажной» тени. Photographs
в низком тёплом свете. Свет: `long-light` (по умолчанию).

## Типографика

- Дисплей: **Yeseva One 400** (заголовки h1–h3, цены в рулированной смете), tracking −0.005em, line-height 1.02.
- Чтение: **Archivo 400/500**, 16–17px, line-height 1.5–1.65.
- Outlier: **Archivo Narrow 600** — только мелочёвка (`.small-print`: подписи, метки, оси) и кнопки. Один outlier, одна роль.
- Размеры: h1 clamp(2.5rem, 4.4vw+0.9rem, 5rem); h2 clamp(2rem, 2.5vw+1rem, 3.5rem); h3 1.5625rem; lead 1.25rem.

## Поверхности

- Кнопочная пара: вермильон-пилл (`.btn.btn-primary`, Archivo Narrow 600 15px, высота 48px) и чернильное подчёркивание 2px (`.btn-secondary`). Nav-действия тише hero.
- Well (`.well`): квадрат, рамка 2px чернильная, золотая hairline inset 6px, жёсткая тень `10px 10px 0 paper-3`. Никаких мягких теней и скруглений на контентах.
- Рулированная строка (`.price-row`): мелочёвка слева, цифра Yeseva 1.375rem справа, золотой пунктир между строк. Сигнатура сайта — сметы на этой строке.
- Банды: максимум две на страницу (paper-2 или один чернильный банд). Вермильон-поле запрещено; вермильон < 5% экрана (posture: restrained).
- Фото: волосяная рамка 10% чернил (`.photo-frame`), без тени; подпись фактом под кадром in the small-print.

## Нав / футер

- Нав: плавающий пилл (бумага-2, рамка 1px чернильная, золотая hairline inset), вордмарк Yeseva.
- Футер: колофон — один блок под чернильной перекладиной, ссылки в весе текста.

## Движение

Quiet: hover = сдвиг цвета или 1px-лифт, 120–220ms, `transform`/`opacity` только.
Ни одного reveal/loop по умолчанию. `prefers-reduced-motion` глобально гасит анимации (global.css).

## Правила копирайтинга

- Без тире (—/–) в тексте: запятая, двоеточие, скобки. Без «eyebrow»-строк над заголовками.
- Числа — из данных (`site/src/data/services`), priceFrom>0 → «от N ₽» (Intl ru-RU), 0 → «по смете».
- Честные обязательства вместо заимствованных наград; факт «гарантия 3 года» не повторяется более двух секций на страницу.
