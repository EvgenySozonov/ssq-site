- Дизайн-система сайта: палитра, шрифты, композиция, компоненты.
- Решения зафиксированы в brainstorm-сессии 2026-10-16 (визуальные варианты — в `.superpowers/brainstorm/`).
- См. также: [product.md](product.md), [architecture.md](architecture.md).

# Направление

**«Ночная медь» + инженерные акценты.** Тёмная премиум-база (эволюция референса `/example/index.html`), поверх — структурные приёмы из «инженерного» направления:

- тёмный фон **#101014** (уточнение к референсу #101010 — чуть холоднее глубина);
- текст **#eceae6**, вторичный **#9a9a9a**;
- акцент — **медь/латунь `#c9a15a`** (кнопки, цифры блоков, пунктирные подчёркивания);
- карточки на фоне **#17191d** с контрастным левым бордером 3px;
- нумерованные блоки `01 / 02 / 03` (моно-цифры — приём взят из Engineering-направления B);
- моно-акценты в деталях: логотип-метка `SSQ //`, телефон, технические подписи.

# Типографика (решение от 2026-10-16)

- Заголовки: **Lora** (антиква, полная кириллица, Google Fonts).
- Текст/UI: **Manrope** (гротеск, полная кириллица).
- Моно-акценты: **JetBrains Mono**.
- Все три — Google Fonts, загрузка с `font-display: swap`.

# Композиция Hero (решение от 2026-10-16)

- **Full-bleed фото объектов** на первый экран, текст поверх, градиент затемнения снизу.
- CTA: «Бесплатный выезд →» (медная кнопка) + телефон моно-шрифтом.
- **Обязательство:** композиция зависит от качества фото; до появления съёмки (5–7 кадров хотя бы одного объекта) — тёмно-бронзовый градиент вместо фото. Съёмка — обязательный шаг до релиза (см. [plan.md](plan.md)).

# Структура главной

1. Hero (full-bleed) → 2. Услуги (карточки направлений) → 3. Стандарты работы (4 проверяемых обязательства — вместо «цифр», т.к. компания новая; тексты — [about.md](about.md)) → 4. Процесс (5 шагов) → 5. Работы (3 последних кейса; блок выводится только при наличии кейсов) → 6. Цены (превью «от …») → 7. Отзывы (блок скрывается, пока отзывов нет) → 8. FAQ (`<details>`, без JS) → 9. CTA-футер «Обсудим ваш проект?».

Каждая секция — отдельный Astro-компонент, данные из `site/src/data/` (см. [architecture.md](architecture.md)).

# Правила

- Русский язык.
- Токены (палитра, шрифты, отступы) — только через CSS-переменные `tokens.css`, в компонентах не хардкодить.
- Анимации уважают `prefers-reduced-motion`.
- BEM-нейминг из референса не переносится: классы даёт Tailwind; смысл — через дизайн-токены и компоненты.
