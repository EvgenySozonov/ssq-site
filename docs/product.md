# Описание

- Продукт: полнофункциональный многостраничный сайт компании «Умный квадрат» (SSQ) — услуги разработки умных домов и электромонтажа. Список услуг со временем расширится.
- Русский язык. Тёмный премиум-дизайн (референс: интерьерная студия, направление «Ночная медь» — см. design.md).
- Первая версия сайта (одностраничная визитка, `example/index.html`) сохранена как референс и будет переработана с нуля на новом стеке (Astro, см. `.planning/codebase/ARCHITECTURE.md`).

# Цели сайта

1. **Заявки** — главный KPI: сообщения с формы (→ Telegram), звонки, повторные визиты. CTA первого экрана — «Бесплатный выезд для замера» (решение от 2026-10-16).
2. **Премиальное позиционирование** — дизайн и кейсы продают вместо скидок; аудитория с чеком от сотен тысяч ₽.
3. **Рост вместе с компанией** — каркас рассчитан на добавление новых направлений услуг без перестройки структуры.

- Владельцы квартир и домов в процессе ремонта/новостройки/мансарды, Москва и область (позже уточнить регионы).
- Поведение: сначала смотрят работы и цены, затем инициируют контакт. Отсюда: сильные `/portfolio/` и `/pricing/`, лёгкий вход через «бесплатный выезд».

# Структура услуг — по направлениям

Услуги не в плоском списке, а **сгруппированы по направлениям** («блок услуги»). Каждое направление — отдельный раздел сайта со своей посадочной страницей:

- **Направление 1. Электромонтаж** (`/services/elektromontazh/`) — разводка электрики, щиты, освещение и т.д.
- **Направление 2. Умный дом** (`/services/umniy-dom/`) — автоматизация, KNX и т.д.
- Новое направление (например, «Солнечные панели») = новая запись в `data/services/lines.json`; каркас построит раздел автоматически. Это требование к архитектуре, закреплено в [`ARCHITECTURE.md`](../.planning/codebase/ARCHITECTURE.md).

Правило контента: направление — структурированные данные (JSON), услуги внутри направления — структурированные данные, статьи-обоснования — место блога.

# Функциональность

- Многостраничный сайт: главная, направления услуг, услуги, портфолио, цены, калькулятор (позже), блог (позже), о компании, отзывы, контакты, юридические страницы. Полная карта — [`ARCHITECTURE.md`](../.planning/codebase/ARCHITECTURE.md).
- Форма заявки → Python-CGI эндпоинт на Beget → уведомление в Telegram. Позже — CRM через замену тела эндпоинта (адаптер).
- Согласие на обработку ПДн (чекбокс + политика) — обязательное требование 152-ФЗ.

# Критерии успеха первого релиза

- Сайт собирается командой `astro build` без ошибок.
- Форма реально доставляет заявки в Telegram.
- Каркас позволяет добавить третье направление правкой одного JSON.
- Скорость на мобильных: оценка Lighthouse ≥ 90 (производительность, SEO).
