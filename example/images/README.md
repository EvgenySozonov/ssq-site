# images

Фотографии и графика сайта.

## hero.jpg — фон hero-секции

Сейчас: кадр, вырезанный из добавленного арта (светящийся круг над «умным городом»
с парящих стеклянных кубов, 612×765, обрезаны элементы интерфейса телефона).

**Чтобы заменить своим фото:** просто положите сюда файл с именем `hero.jpg`
(рекомендация: 2400×1600, горизонтальный, тёмное/приглушённое фото объекта).
Подключение уже прописано в `assets/css/style.css` — правки кода не нужны.
Кадр вертикальный, поэтому по бокам на широких экранах его мягко затеняет
скрим-градиент: на тёмном фото это выглядит органично.

## hero.png / hero.svg

Резервные фоны (сгенерированная тёмная иллюстрация с электрощитом).
Показываются, только если `hero.jpg` недоступен. Можно удалить.

## Фото объектов

Плейсхолдеры в блоках «Студия» (`.about__photo`) и «Работы» (`.case__photo`).
Когда появятся фото объектов — заменим на `object-01.jpg` … `object-05.jpg`.
